digitalloco is hardware and firmware for digital model railways: a
DCC command station and track detectors, with RailCom, the channel
by which a decoder talks back, at the centre. It is currently a
hobby project; nothing is for sale.

The site exists because the useful part of the work so far is not
code. It is what the standards say, what decoders do when you put
them on a scope, and the gap between the two. That belongs
somewhere people will find it, and a repository README is not that
place.

Three pages are here now. The
[RailCom introduction](/docs/railcom/introduction/) is for someone
who runs DCC with ordinary block detection and has never heard of
RailCom. The [RailCom standards](/docs/railcom/standards/) page
says which documents define it, which edition is current and which
to read first. And
[which RailCom decoder does what](/docs/railcom/decoders/) indexes
decoders by maker and model with the RailCom features each one has.
It is under construction; every cell says yes, no or not
established, and never leaves a blank.

The blog is for the stories behind those pages, roughly in the
order they happened. The dates are approximate, because the work
came before the site.

Source code is on [GitHub](https://github.com/digitalloco).
